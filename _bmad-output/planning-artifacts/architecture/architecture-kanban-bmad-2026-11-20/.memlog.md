- (direction) Paradigm: classic layered (controller->service->repository->dto->mapper) on Spring Boot 3; standalone-component signal-reactive on Angular 18; two independently-deployable processes talking HTTP/JSON over localhost. Pre-settled by brief Solution + PRD NFR-8.
- (decision) AD-1 [ADOPTED] Dependency direction (layered): controller -> service -> repository; mapper straddles dto<->entity; dto<-> controller boundary only. Entities NEVER leave the service layer. Prevents controllers touching JPA repos directly, services returning entities to controllers, and cross-service calls (controllers compose, services do not depend on peers). PRE-SETTLED by NFR-8.
- (decision) AD-2 Error envelope: every HTTP error from /api/** returns {error: <CODE_UPPER_SNAKE>, message: <localized or EN fallback>}. Exceptions bubble up to a single @RestControllerAdvice. AI failures = HTTP 503 AI_UNAVAILABLE (FR-26). Validation errors = HTTP 400 VALIDATION_FAILED. Not-found = HTTP 404 NOT_FOUND. Prevents per-endpoint drift in error shape and frontend toast mapping.
- (decision) AD-3 Enum ownership (status + priority): the server-side Java enums are authoritative. REST accepts and emits them as UPPER_CASE strings (TODO|IN_PROGRESS|DONE and LOW|MEDIUM|HIGH). Jackson default enum serialization. Frontend declares matching union types manually (no generated client for MVP). Column identity is derived from status; there is no Column entity. PRE-SETTLED by PRD + addendum. Prevents parallel string tables, string-vs-int drift, hidden column entity.
- (decision) AD-4 Position recomputation is server-owned. On any card create/move the server renumbers positions within the affected status(es) 0..n-1 before returning, and the payload echoes the authoritative list. Prevents FE+BE computing different orderings and a 'position gaps' bug class. Addendum schema hard-codes 'renumber-on-insert, no gap management'.
- (decision) AD-5 AI response validation happens in AiBreakdownService BEFORE the controller returns 200. A strict Jackson-schema validator rejects anything that is not {cards:[{title,description,priority}]} with 4..6 cards; invalid payload maps to 503 AI_UNAVAILABLE (never 200 with empty cards, never partial). PRE-SETTLED by FR-29. Prevents the UI parsing partial/invalid LLM output.
- (decision) AD-6 AI capability is runtime-probed, never compile-time flagged. The @ConditionalOnProperty on ANTHROPIC_API_KEY omits the AiBreakdownController and its dependencies from the bean graph when absent. GET /api/config returns {aiEnabled, locales} as the sole signal the frontend reads. The frontend never checks the API key itself or feature-flags AI in a build. Prevents env drift between containers/dev machines and frontend code assuming AI exists. PRE-SETTLED by FR-24/FR-25.
- (decision) AD-7 Transaction boundary: @Transactional lives on service methods only (never on controllers, never on repositories). Read-only operations use @Transactional(readOnly=true). Prevents controllers composing transactions and lazy-init exceptions crossing the HTTP boundary.
- (decision) AD-8 Frontend optimistic-update contract: for drag/drop and inline edit, the FE mutates its signal state immediately and fires PATCH; on non-2xx or network error it rolls back to the pre-mutation snapshot AND surfaces a toast. AI-accept flow is NOT optimistic — cards persist via POST /api/cards/batch and only enter the board on 2xx. Prevents two incompatible update strategies across card interactions.
- (decision) AD-9 Angular state convention: a single BoardStore service holds board state as signals (cards: WritableSignal<Card[]>). Components read via computed() / effect() only — never mutate the signal directly. CDK drag-drop events route through BoardStore. HTTP calls are isolated to ApiService; BoardStore talks to ApiService and never injects HttpClient directly. Prevents two patterns: half the components doing HTTP themselves, half via the store.
- (decision) AD-10 Localization split: UI chrome (labels, buttons, placeholders) is translated via ngx-translate keys in fr.json/en.json loaded at bootstrap. AI-generated card content is never retranslated — stored verbatim in the locale it was generated in, stamped with lang attribute on the DOM node at render (EXPERIENCE.md Finding 9). User-typed content (manual card titles/descriptions) is also never translated. Prevents a retranslation bug and sets a clear rule for card.aiGenerated handling.
- (decision) AD-11 Test shape: unit tests cover AiBreakdownParser/Validator and anything with branching domain logic; @WebMvcTest covers each controller CRUD path; one @SpringBootTest integration test exercises create->persist->restart-mock->read for H2 durability. No E2E, no Playwright for MVP. PRE-SETTLED by NFR-7. Prevents over-testing the Angular side or under-testing the AI parser (the single riskiest unit).
- (decision) AD-12 CORS: Spring allows origin http://localhost:4200 only, methods GET/POST/PATCH/DELETE/OPTIONS, allowed headers Content-Type + Accept-Language; no credentials. Hard-coded in a @Configuration class (not externalized). Prevents production-ready CORS plumbing creeping in and a '* origin' accident. Implicit in brief but worth binding.
- (version) Spring Boot 3.3.x, Java 21 (LTS); Angular 18.2.x + @angular/cdk 18.2.x; H2 2.2.x (embedded file); ngx-translate 15.x compatible with Angular 18; Anthropic Java SDK not used — WebClient direct POST to https://api.anthropic.com/v1/messages with model claude-opus-4-7. [ASSUMPTION] exact minor versions to be pinned against https://start.spring.io and https://angular.dev at project init.
- (decision) AD-13 API surface shape: all endpoints under /api/*. Resources use plural lowercase (cards). AI namespace under /api/ai/*. Config probe at /api/config. Request/response bodies are JSON. No versioning (/v1) — single-version MVP. No pagination (board is small). Prevents inconsistent URL styles emerging per controller.
- (decision) AD-14 Data invariants on Card: id = server-generated UUID (string on wire); createdAt = @CreationTimestamp (ISO 8601 UTC on wire); position = zero-indexed int per status, unique within status; aiGenerated = immutable flag set at creation. The server rejects client-provided id or createdAt on create. Prevents id spoofing, time drift, position mutation outside the ordering API.
